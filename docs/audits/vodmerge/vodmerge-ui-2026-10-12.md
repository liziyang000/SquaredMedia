# VodMerge 1.3.1 页面优化与部署

2026-10-12：1.3.1 已部署到 `/www/wwwroot/squaredMedia`，刷新 [后台采集审核](https://www.ping2video.xyz/squaredMediaAdmin.php/admin/vodmerge/index.html) 即可使用。

## 页面变化

- 首屏以采集任务为主，AI 设置收进独立弹窗。空列表说明任务从哪里来，读取失败提供重试；搜索和状态筛选明确只作用于本页。
- 详情按“查看采集 → 比较影片 → 预览变化 → 确认合并”组织。采集资料与候选分栏显示，冲突单独标注，选择目标后引导预览；预览显示目标片名、新增线路和集数。
- 已完成任务展示记录，按钮按服务端任务状态启用。目标或线路改变时旧预览失效；操作失败后重读任务也不会恢复旧确认按钮。正在操作时锁定按钮与输入。
- Token 不回显，测试与保存分开反馈，“已配置”不代表连通性已测试；高级连接管理和任务操作折叠。手机任务表转为卡片。

相对 1.3.0 安装包仅修改五个插件文件：后台模板、`Service::detail()` 的操作能力与预览期限、版本说明、README 和验证记录；匹配、Jev 请求与合并写入逻辑沿用原版本。

## 验证

全仓库 `npm test`、lint、模板 lint、compat 和 preview 验证通过；VodMerge 279 项断言（包含 69 项匹配断言）、508 项配置检查通过，13 个 PHP 文件和内联 JavaScript 语法通过。

Headed Chromium 在 1440px 桌面和 390px 手机验证空／加载／错误、筛选、候选选择、预览、确认与 Token 设置。模拟接口归档 9 次 POST，全部含双 CSRF 和 XHR；延迟请求、切换任务、选项变化及失败后旧 Token 重现均通过。随后用服务器取回的实际 `layui.css`、`admin_style.css`，不加人工 reset，再测空页、详情和弹窗，手机无横向溢出。

截图与请求记录位于 `output/playwright/vodmerge-ui/`。这些浏览器截图使用本地模拟接口和虚构影片，不是已登录生产页面截图；公共 head 的 JavaScript 未在本地模拟中执行。生产端已分别以 root 与站点 PHP 用户 www 用原生 ThinkPHP 编译新版模板和实际公共 head，均通过。

Jev 辅助检查通过指定请求脚本发送匿名虚构流程后实际返回 HTTP 451，未获得模型判断。没有发送本轮私有源码、截图、真实影片或密钥；本轮不作为真实 Jev 匹配准确性／速度的新测试。
