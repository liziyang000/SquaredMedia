## 本批交付

- **待处理**：跨排查轮次保留未完成事项，支持全候选搜索、规则依据和处理状态筛选、分页；历史扫描依据与当前资料冲突分别显示。
- **人工审核**：并排核对影片资料，记录同片、不同影片、待补资料、稍后处理及恢复结论。身份结论与资源处理状态分别保存；资料变化后要求重新核对。
- **合并预览**：确认身份后明确选择资源接收方，不默认选择；按线路及播放条目展示保留、新增和数量变化。换接收方、修改选项或离开页面会使旧确认失效。最终确认及条件回滚沿用原有快照、并发和权限保护。
- **处理记录**：保存操作者、时间、理由和任务引用；已有资源任务可追溯，不补造历史人工结论。采集入库、排查计划及 AI 设置各有独立入口。

资源合并的含义仍是向接收方补充资源，双方影片记录和 ID 均保留；本批未实现删除来源、隐藏来源或前台条目归一。

## 生产数据与性能

导入既有 240,811 对疑似结果，待处理 93,251 对。比原列表少的一对来自识别既有已执行任务 `#3`，不是本次新合并；原已执行任务内容校验未变。

生产服务器一次请求实测：默认待处理列表约 **2,005ms**，影片 ID 搜索约 **71ms**，片名“潜行”搜索约 **1,509ms**（75 对结果）。这些是当前库规模下的单次样本，包含查询逻辑，不含浏览器渲染和网络，也不是 P95 或影片匹配准确率。首次名称索引构建约 200 秒；验收 JSON 中 `import_ms=124` 是跳过已完成索引构建后的任务引用同步耗时，不能解释为全量导入时间。

最终核验：

- 29 个插件包文件及 3 个激活到应用目录的文件与安装包匹配。
- 抽验影片完整行、影片总量及更新时间聚合保护值未变；扫描状态、插件配置、Cron 文件和原已执行任务未变。
- 新增两张插件表、所需字段及索引；升级未重新启动全库排查。周计划保持原值，下一轮为 **2026-10-19 20:08:14**（北京时间），新增 ID 水位 `705362`。
- 部署后可用空间 `4,507,521,024` 字节（约 4.20 GiB）。

搜索边界：名称和别名取最近排查或人工审核时建立的索引；数字 ID 定位及审核页资料、资源预览实时读取。旧影片改名后尚未重新排查或审核时，名称搜索可能保留旧名称。名称命中超过 5,000 对会明确要求缩小条件，不会静默截断。旧 ID 索引刷新、原 1,794 条候选截断的补查及召回准确率提升属于后续批次。
