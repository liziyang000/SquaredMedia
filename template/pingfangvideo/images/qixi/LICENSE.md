Changes made for this theme: glTF Transform 4.4.2 was used to simplify the geometry with a 35% target and 1% error tolerance, quantize mesh attributes, and resize embedded textures to 512px WebP. The page uses the model geometry only as a particle-sampling surface: all `Petals*` surfaces use a pink-and-blue particle palette, while leaves, stems, small plants, and ribbon keep separate particle colors. The broken `Leaves6` UV islands are omitted.
