- **结果**：最直接的方法是在网站根目录的 `robots.txt` 中加入： ```txt User-agent: GPTBot Disallow: / ``` 确保能通过以下地址访问： ```text https://你的域名/robots.txt ``` 这会要求 GPTBot 不再抓取全站，并表示网站内容不得用于 OpenAI 基础模型训练。GPTBot 与 ChatGPT 搜索使用的 `OAI-SearchBot` 相互独立，因此这样不会自动屏蔽 ChatGPT 搜索收录。[OpenAI 爬虫官方说明](https://developers.openai.com/api/docs/bots) 如果仍希望出现在 ChatGPT 搜索结果中，可以明确写成： ```txt User-agent: GPTBot Disallow: / User-agent: OAI-SearchBot Allow: / ``` 如果需要强制拦截，而不只是依靠爬虫遵守 `robots.txt`，可再配置服务器返回 `403`。 Nginx： ```nginx if ($http_user_agent ~* "GPTBot") { return 403; } ``` Cloudflare： ```text http.user_agent contains "GPTBot" ``` 对应操作选择 `Block`。不过 User-Agent 可以伪造；更严格时应结合 OpenAI 公布的 [GPTBot IP 段](https://openai.com/gptbot.json)配置防火墙，并定期同步更新。`ChatGPT-User` 属于用户主动发起的访问，官方说明其不一定遵守 `robots.txt`，需要单独在 WAF 中拦截。
