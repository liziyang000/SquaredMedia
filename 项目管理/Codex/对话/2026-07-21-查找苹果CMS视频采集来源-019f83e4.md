## 对话记录

### 1. 2026-07-21 16:57

- **用户请求**：苹果cms的数据库能否看到哪个视频是从哪里采集到的数据吗

- **结果**：可以，但通常只能“部分追溯”，不一定能精确对应到某个采集接口。 重点看这些字段： - `mac_vod.vod_reurl`：来源地址。非空时最直接；官方字段说明也将其定义为“来源地址”。[苹果CMS 视频字段文档](https://www.maccms.la/theme/theme-vod) - `mac_vod.vod_play_from`：播放源编码，例如 `lzm3u8`、`ikm3u8`。它是播放器/播放组标识，不是采集站外键。[苹果CMS 采集接口文档](https://www.maccms.la/apis/collect) - `mac_vod.vod_play_url`：播放地址，可以通过域名辅助判断资源来源。 - `mac_collect.collect_name`、`collect_url`：后台配置过的资源站名称和采集接口。 在苹果CMS后台数据库工具中可执行： ```sql SELECT vod_id, vod_name, vod_reurl, vod_play_from, vod_play_url, vod_time_add, vod_time FROM {pre}vod WHERE vod_name LIKE '%视频名称%'; ``` 查看配置过的资源站： ```sql SELECT collect_id, collect_name, collect_url FROM {pre}collect WHERE collect_mid = 1; ``` 需要注意：默认的 `vod` 表通常没有 `collect_id`，所以不能直接和 `collect` 表精确关联。当前项目中的脚本也是读取资源站配置后，再通过 `vod_play_from` 推测来源，而不是数据库直接关联：[repair-vod-posters.php](scripts/repair-vod-posters.php:318)。 因此： - `vod_reurl` 有值：可以较准确看到来源地址。 - `vod_reurl` 为空但 `vod_play_from` 明确：可以大致判断资源站。 - 两者都不明确：只能从 `vod_play_url` 域名推断。 - 同一视频被多个资源站更新过：现有数据库通常无法还原完整采集历史。
