### 3. 2026-07-21 14:10

- **用户请求**：301代表什么

- **结果**：`301` 是 HTTP 状态码，表示“永久重定向”。 例如用户访问旧地址： ```text /index.php/vod/detail/id/367756.html ``` 服务器返回： ```http HTTP/1.1 301 Moved Permanently Location: /vod/367756 ``` 浏览器会自动打开： ```text /vod/367756 ``` 它的效果是： - 地址栏会变成新 URL。 - 搜索引擎会逐步把旧页面权重转移到新页面。 - 收藏夹、外链和历史搜索结果中的旧地址仍然有效。 - 浏览器和 CDN 可能长期缓存这个跳转。 与其他方式的区别： - `301`：永久跳转，地址栏改变，适合正式更换 URL。 - `302`：临时跳转，不表示旧地址被永久替代。 - `rewrite`：服务器内部转发，地址栏仍显示旧地址。 所以，如果你希望用户最终看到干净的 React 地址，就用“旧 `index.php` 地址 → 301 → 新地址”。如果希望地址栏永远不变，则使用内部 rewrite。
