### 2. 2026-07-23 10:53

- **用户请求**：type_id_1是什么

- **结果**：`type_id_1` 表示视频所属的一级栏目，`type_id` 表示具体栏目。 例如： - 日本动漫：`type_id = 58`，`type_id_1 = 57（动漫）` - 喜剧片：`type_id = 100`，`type_id_1 = 47（电影）` - 视频直接放在短剧父栏目：`type_id = 42`，`type_id_1` 也应是 `42`，不能是 `0` 当前网站的正确规则是： ```sql type_id_1 = CASE WHEN mac_type.type_pid = 0 THEN mac_type.type_id ELSE mac_type.type_pid END ``` 它主要用于按“电影、电视剧、动漫、综艺、短剧”等大类筛选、统计和权限判断。修复 `type_id_1` 不会改变视频当前的具体分类，只会恢复它和一级栏目的正确关联。 当前库发现的 44,057 条异常，基本都是视频直接位于父栏目，但 `type_id_1` 被错误保存成了 `0`。
- **轮次状态**：completed
