# 建立 Obsidian 项目管理数据库

## 项目目标

建立一个基于 Obsidian Bases 和 Markdown 属性的轻量项目管理系统。

## 成功标准

- [x] 项目记录使用统一字段。
- [x] 项目、任务和里程碑分别使用统一字段。
- [x] 支持总览、近期截止、已逾期、阻塞和已完成视图。
- [x] 项目页自动展示关联任务和里程碑。
- [x] 提供三级记录模板和日常仪表盘。
